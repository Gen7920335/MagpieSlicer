서로 다른 노즐 구경, 확장된 서포트, GPU 보조 슬라이싱을 하나로 통합한 OrcaSlicer 기반 포크

- 버전: **2.5.0.0.9 Beta 6**
- 태그: `v2.5.0.0.9-beta.6` (게시 전)
- 플랫폼: **Windows x64**
- 상태: **Pre-release**

기준 커밋과 SHA-256은 GitHub 릴리스 본문에서 확인할 수 있습니다.

Beta 6 주요 변경:

- Snapmaker U1 기본값을 Snapmaker 공식 Orca 값으로 맞췄습니다. 가속 20,000·속도 500 mm/s(순정 펌웨어 한계), 노즐별 리트랙션, 트리 서포트·Classic 벽 기본 프로세스가 적용되며, 기본 판은 Textured PEI로 읽혀 `Z_OFFSET -0.07`이 붙지 않습니다.
- 절반 높이 외벽(H/2)을 켜면 절반 높이 서포트가 함께 켜지고, 서포트가 있어도 외벽 반층 사이 시간이 고르게 되도록 출력 순서를 바꿨습니다. 미리보기도 반층 단위로 한 칸씩 나뉩니다.
- Vulkan 드라이버(로더)가 없는 PC에서도 앱이 실행되고 CPU로 슬라이스합니다.
- Classic 벽 + H/2 + 벽 4겹에서 슬라이스가 실패하던 문제, 일반 서포트 바닥층 외곽선 누락, 툴헤드별 선폭 범위 검사 누락, 저온 인터페이스 온도 범위 검사 누락 등을 고쳤습니다.
- 프로그램 목록과 설치파일 이름에 베타 번호가 표시되고, 파일 연결이 OrcaSlicer와 분리됩니다.

자동 검증 범위와 설치본 GUI·실출력 등 남은 제한은 개발 문서에 구분해 기록합니다.

> 개발 중인 포크입니다. 실제 장비에서 출력하기 전에 미리보기와 생성된 G-code를 확인하십시오.

## 핵심 기능

| 기능 | 용도 |
| --- | --- |
| 멀티 노즐 벽 출력 | 큰 노즐로 내부를 빠르게 만들고 작은 노즐로 글자와 날카로운 외벽 출력 |
| 멀티 노즐 인터락킹 | 소구경 외벽과 대구경 내벽의 경계를 레이어마다 이동해 박리 억제 |
| 대구경 핫엔드 오버라이드 | 강도가 필요한 레이어 범위를 지정 핫엔드로 강제 출력 |
| `Nozzle used` 미리보기 | 재질 색상과 무관하게 실제 사용 노즐을 색상으로 구분 |
| Cura 스타일 일반 서포트 | 기존 Prusa 스타일과 별도로 연속적인 Cura식 서포트 경로 제공 |
| Mixed 자동 서포트 | 베드 직결 가능 영역은 일반, 나머지는 트리로 분할해 한 출력에서 융합 |
| Resin style 자동 서포트 | PrusaSlicer SLA Default/Branching 지지대를 FFF 인터페이스·재질·툴패스로 출력 |
| Bambu Lab A2L 프로파일 | 0.2/0.4/0.6/0.8 mm 노즐별 기기·공정·필라멘트 프리셋 제공 |
| 삼각형 인터페이스와 서브레이어 | 인터페이스 일부의 패턴, 각도, 온도를 독립 조절 |
| 저온 인터페이스와 온도 드롭 타워 | 싱글 노즐에서 모델과 인터페이스의 출력 온도를 분리 |
| 트리 서포트 벽 수 | 트리 가지를 최대 10겹 벽으로 보강 |
| Vulkan 보조 슬라이싱 | Auto, On, Max GPU, Off 모드로 GPU 가속 범위 선택 |
| LESIC | 온도와 체적 속도를 함께 확인하는 통합 캘리브레이션 모델 |

## 멀티 노즐

### 핫엔드별 설정

각 툴헤드는 독립적인 노즐 구경과 선폭을 가집니다. 툴헤드 선택부, 프린터 압출기 설정, `Hotend` 설정은 같은 노즐 구경 원본값을 사용하며 프로젝트와 프리셋에 함께 저장됩니다.

주요 설정은 다음과 같습니다.

- 노즐 직경과 기본 선폭
- 첫 레이어, 외벽, 내벽, 상단 표면, 인필, 서포트 선폭
- 핫엔드 설정과 필라멘트 설정의 개별 저장·불러오기
- 소구경 벽 속도 오버라이드

### 소구경 노즐 자동 선택

`Use smaller nozzles in crisp corners`를 켜면 사용 가능한 핫엔드 중 작은 노즐을 찾습니다. 큰 노즐 경로가 외곽 일부라도 채우지 못하는 연결된 벽 루프는 노즐 전환 자국이 중간에 생기지 않도록 루프 전체를 소구경 노즐로 출력합니다. 안쪽 벽과 인필은 가능한 범위에서 대구경 노즐을 유지합니다.

- 소구경 벽 수는 일반 벽 수와 별도로 지정합니다.
- 공간이 부족하면 소구경 외벽을 우선 보존합니다.
- Classic과 Arachne 벽 생성기를 지원합니다.
- 2번 툴이 더 큰 노즐이면 1번 툴을 소구경으로 역선택할 수 있습니다.

### 멀티 노즐 인터락킹

인터락킹을 켜면 소구경 벽과 대구경 벽의 경계를 홀수·짝수 레이어마다 한 줄 이동합니다.

```text
대 대 대 소 소 소 소
대 대 대 대 소 소 소
대 대 대 소 소 소 소
대 대 대 대 소 소 소
```

벽과 인필의 접촉 경계만 이동하며 인필 패턴 자체는 레이어마다 흔들리지 않습니다.

### 대구경 핫엔드 오버라이드

시작·종료 레이어와 사용할 핫엔드를 지정하면 해당 범위의 소구경 자동 판정을 무시합니다. `Add region`으로 여러 범위를 추가할 수 있으며, 겹치거나 역순으로 입력된 범위는 정규화해서 처리합니다.

### 미리보기

- `Nozzle used`: 노즐 직경별 고정 색상
- `Layer width`: 실제 압출 선폭
- 슬라이싱 시간: G-code 생성과 후처리 완료까지 포함

## 서포트

### Cura 스타일 일반 서포트

기존 Orca/Prusa 스타일 일반 서포트와 트리 서포트를 유지하면서 다음 선택지를 추가했습니다.

- `Normal (Cura style) auto`: 임계각 기반 자동 생성
- `Normal (Cura style)`: 수동·강제 서포트 영역 사용

Cura 스타일은 필요한 영역을 레이어 방향으로 전달하고 연속 ZigZag 경로를 생성합니다. 서포트 토글이 꺼져 있으면 Cura 생성기를 실행하지 않습니다.

`Cura solid support raft`를 켜면 Cura 스타일 서포트의 바닥 첫 층을 100% 채워 베드 접착력을 높입니다. 이 설정은 일반 자동 서포트를 강제로 활성화하지 않습니다.

### 인터페이스

- 삼각형 패턴은 120도 간격의 세 방향만 사용합니다.
- `Interface density / spacing`의 두 값은 서로 변환되어 함께 갱신됩니다.
- 인터페이스 출력 핫엔드를 지정하면 해당 노즐 직경과 서포트 선폭을 사용합니다.
- 지정한 인터페이스 두께를 유지하며 아랫면 스무딩으로 곡면 계단을 완화합니다.

### 인터페이스 서브레이어

모델과 직접 접촉하는 면을 1번으로 보고, 지정한 시작·종료 레이어에만 별도 설정을 적용합니다.

- 기능 켜기/끄기
- 시작·종료 레이어
- 패턴
- 각도
- 온도

범위 끝이 총 인터페이스 레이어 수보다 크면 자동으로 마지막 레이어에 맞추며, 인터페이스가 한 겹뿐이면 비활성화됩니다.

### 저온 인터페이스

싱글 노즐에서 모델과 서포트 인터페이스의 출력 온도를 분리합니다.

```text
모델 -> 서포트 본체 -> 냉각/온도 전환 -> 인터페이스 -> 재가열 -> 다음 레이어
```

온도 드롭 타워는 슬라이싱 전부터 보이고 사용자가 직접 옮길 수 있습니다. 5줄 브림을 사용하며 자동으로 모델을 피해 이동하지 않습니다.

- 온도 차이 30도 이하: 기본 경로 50 mm
- 30도 초과: 1도마다 1 mm 추가
- 최대 경로: 80 mm
- 마지막 10 mm: 10 mm/s
- AUX 팬 냉각과 노즐 와이핑은 지원 하드웨어 프로파일에서만 활성화

### 트리 서포트

- 자동 트리 모드에 설정한 임계각을 실제 오버행 감지에 전달합니다.
- Tree Slim과 Organic의 벽 수를 `0~10`으로 지정할 수 있습니다.
- `0`은 기존 자동값이며, 좁은 가지는 실제로 들어갈 수 있는 벽까지만 생성합니다.

### 절반 높이 외벽·서포트 (H/2)

- `Half-height outer walls`: 바깥 XY 벽 2줄을 모델 레이어 높이의 절반으로 두 번 출력합니다. 전체 벽 수는 바뀌지 않습니다.
- `Half-height support`: 서포트를 절반 높이로 출력합니다. 절반 높이 외벽을 켜면 외벽을 받치기 위해 항상 함께 켜집니다.
- 한 레이어 안에서는 아래 반층(서포트·외벽)을 먼저 찍고 위 반층으로 올라갑니다. 위 외벽은 두 외벽 패스 사이 시간이 고르게 되는 위치에 넣어, 반층마다 줄무늬가 생기지 않게 합니다.

## Vulkan 보조 슬라이싱

상단 선택창에서 다음 모드를 사용할 수 있습니다.

- `Vulkan: Auto`: CPU/GPU 정보를 기준으로 이득이 예상되는 작업만 자동 사용
- `Vulkan: On`: 검증된 GPU 경로를 우선 사용
- `Vulkan: Max GPU`: GPU 적용 범위를 최대로 확장
- `Vulkan: Off`: 기존 CPU 경로만 사용

결과 형상의 안정성이 중요한 단계에는 검증과 CPU 대체 경로가 유지됩니다. GPU 성능, 드라이버, 모델 복잡도에 따라 가속 효과가 달라질 수 있습니다. Vulkan 로더가 설치되지 않은 PC에서는 Vulkan을 켜 두어도 CPU로 슬라이스합니다.

## 장치와 캘리브레이션

### Snapmaker 장치 화면

Snapmaker U1용 기본 출력 시작 순서와 네이티브 장치 패널을 확장했습니다. 카메라, 현재 레이어, 온도·팬·이동 상태와 자주 사용하는 장치 제어를 한 화면에서 확인할 수 있습니다. PA 캘리브레이션, 베드 레벨링, 타임랩스 선택창은 기본적으로 꺼진 상태로 표시됩니다. U1 프린터·기본 프로세스 값은 Snapmaker 공식 Orca(2026-09-30)와 맞춥니다.

### LESIC

베드 크기에서 20 mm를 뺀 원통형 캘리브레이션 모델을 중앙에 생성합니다. 바닥 숫자, 외곽 눈금, 내부 브림을 포함하며 소형 베드에서는 글자 크기와 굵기를 조정합니다. 온도와 최대 체적 속도를 한 모델에서 함께 확인할 수 있습니다.

## 검증 현황

Beta 6에서 완료한 검증:

- 단위·통합 시험: fff_print **164개**(1개 skip), libslic3r **206개**, half-layer **69개** 통과
- 설치파일 내용: **15,250개 파일**, 설치파일 속 EXE/DLL과 빌드 결과의 SHA-256 일치
- 설치파일 속 프로그램 CLI 슬라이스: U1 기본값 Benchy에서 CPU와 Vulkan 결과 동일, Vulkan 로더가 없어도 정상 종료

실제 관리자 설치·제거, 설치본 GUI, 실출력은 이번 베타에서 확인하지 않았습니다.

검증을 통과했다는 것이 모든 프린터와 펌웨어에서의 동작을 보증하지는 않습니다. 특히 멀티 툴 출력, 장치 전용 시작 G-code, 저온 인터페이스는 장비에 업로드하기 전에 확인하십시오.

## 빌드

Windows용 기본 빌드는 저장소의 빌드 스크립트를 사용합니다.

```powershell
cmake --build build-vulkan --config Release --parallel 2 -- /p:CL_MPCount=2 /nodeReuse:false
powershell -ExecutionPolicy Bypass -File scripts\build_installer.ps1 -BuildDirectory build-vulkan
```

설치파일 빌드 스크립트는 시스템 응답성을 보호하기 위해 CMake와 MSVC의 병렬 작업을 각각 최대 2개로 제한하고, 빌드·패키징을 낮은 프로세스 우선순위로 실행합니다. 다른 빌드가 실행 중이거나 가용 메모리가 8 GiB, 스테이징 디스크가 20 GiB보다 적으면 패키징을 시작하지 않습니다.

## 라이선스 및 출처

Magpie Slicer는 [OrcaSlicer](https://github.com/OrcaSlicer/OrcaSlicer)를 기반으로 합니다. OrcaSlicer 고유 캘리브레이션 도구와 모델 이름은 원본 명칭을 유지합니다. 사용 및 배포 조건은 저장소의 [LICENSE](LICENSE.txt)와 원본 프로젝트의 라이선스를 확인하십시오.
