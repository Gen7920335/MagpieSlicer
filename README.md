## 2.5.0.1.0에서 달라진 점

- **OrcaSlicer 프로파일 가져오기:** OrcaSlicer 사용자 프로파일을 맥파이에 맞게 변환해서 가져옵니다. 맥파이에 없는 벤더(Voron, BBL 등)를 부모로 쓰는 프리셋도 값이 그대로 담긴 독립 프리셋으로 정상 로드되고, 오르카 계정 폴더의 프리셋도 기본 폴더로 합쳐집니다. 새로 설치한 경우 Snapmaker·Voron처럼 필요한 프린터 프로파일을 먼저 설치해 U1 프리셋이 원래 부모와 연결된 채로 들어옵니다. 실제 사용자 프리셋 62개를 오르카가 읽는 값과 하나씩 비교해 모두 일치했습니다.
- **U1 툴헤드별 값:** 툴헤드 목록이 저장되지 않은 예전 U1 프린터 프리셋도 툴헤드 2~4의 z 홉·리트랙션 등이 툴헤드 1 값으로 덮이지 않고 유지됩니다.
- **시작 시 크래시:** 압출기 variant는 있고 압출기 ID가 없는 프린터 프리셋을 읽을 때 맥파이가 시작하다 종료되던 문제를 고쳤습니다.

## Beta 7에서 달라진 점

- **툴헤드 재료:** 사이드바 편집 버튼이 아닌 다른 방법으로 연 툴헤드/재료 설정 창에서 재료를 바꿔도 이제 그 툴헤드의 슬라이스 설정에 반영됩니다. 창 제목에 편집 중인 툴헤드(T번호)가 표시됩니다.
- **예전 프로젝트의 툴헤드 지정:** Orca 2.3 이전에 저장한 3MF의 벽·인필 재료 지정은 다시 기본값으로 동작해, 객체·파트에 지정한 툴헤드가 우선합니다. 이전에는 툴헤드 1에 지정한 TPU 파트가 거의 전부 다른 재료로 출력됐습니다.
- **미리보기:** Filament 보기와 범례가 노즐 색 대신 각 툴헤드의 재료 색을 보여줍니다.
- **래프트:** Cura 스타일 서포트에서 래프트가 한 층만 나오고 객체 밑 래프트가 빠지던 문제, Resin 서포트에서 래프트 3층 이상이면 슬라이스가 멈추던 문제를 고쳤습니다.
- **Resin 띄움:** 객체 띄움은 서포트를 켰을 때만 적용됩니다. 서포트를 끄면 객체가 바닥에 놓여 정상적으로 슬라이스됩니다.

## Beta 6에서 달라진 점

- **Snapmaker U1 기본값 정리:** 프린터·기본 프로세스 값을 Snapmaker 공식 Orca(2026-09-30)에 맞췄습니다. 가속 20,000·속도 500 mm/s(순정 펌웨어 한계), 노즐별 리트랙션, 트리 서포트·Classic 벽 기본값이 적용됩니다. 기본 판은 Textured PEI로 읽혀 매끈한 판 전용 `Z_OFFSET -0.07`이 붙지 않습니다.
- **절반 높이 외벽(H/2):** 켜면 절반 높이 서포트가 함께 켜집니다. 서포트가 있어도 두 외벽 패스 사이 시간이 고르게 되도록 출력 순서를 바꿨고, 미리보기 슬라이더도 반층 단위로 한 칸씩 움직입니다.
- **안정성:** Vulkan 로더가 없는 PC에서도 실행됩니다. Classic 벽 + H/2 + 벽 4겹 슬라이스 실패, 일반 서포트 바닥층 외곽선 누락, 툴헤드별 선폭과 저온 인터페이스 온도의 범위 검사 누락을 고쳤습니다.
- **설치:** 프로그램 목록과 설치파일 이름에 베타 번호가 표시되고, 제거할 때 Magpie가 만든 파일 연결을 정리합니다.

## 핵심 기능

| 기능 | 하는 일 |
| --- | --- |
| 멀티 노즐 벽 | 내부는 큰 노즐로 빠르게, 글자·날카로운 외벽은 작은 노즐로 출력 |
| 멀티 노즐 인터락킹 | 소구경·대구경 벽 경계를 레이어마다 한 줄씩 엇갈려 박리 억제 |
| 대구경 핫엔드 오버라이드 | 강도가 필요한 레이어 구간을 지정한 핫엔드로 출력 |
| 절반 높이 외벽·서포트 (H/2) | 바깥 벽 2줄과 서포트를 레이어 높이의 절반으로 출력해 표면 품질 향상 |
| Cura 스타일 일반 서포트 | 기존 Prusa 스타일과 별도로 연속 경로의 Cura식 서포트 |
| Mixed 자동 서포트 | 베드에 닿는 곳은 일반, 나머지는 트리 서포트로 한 출력에서 결합 |
| Resin 스타일 자동 서포트 | PrusaSlicer SLA 지지대를 FFF 인터페이스·재질로 출력 |
| 삼각형 인터페이스·서브레이어 | 인터페이스 일부 층의 패턴·각도·온도를 따로 지정 |
| 저온 인터페이스 | 노즐 하나로 모델과 서포트 인터페이스를 다른 온도로 출력 |
| 트리 서포트 벽 수 | 트리 가지를 최대 10겹 벽으로 보강 |
| GPU 보조 슬라이싱 | Vulkan 또는 CUDA로 일부 계산을 가속, 결과는 CPU 기준으로 검증 |
| LESIC | 온도와 체적 유량을 한 모델로 확인하는 캘리브레이션 |
| `Nozzle used` 미리보기 | 재질 색과 상관없이 실제 사용 노즐을 색으로 구분 |

## 멀티 노즐 출력

- **핫엔드별 설정:** 툴헤드마다 노즐 직경과 선폭(첫 레이어, 외벽, 내벽, 상단, 인필, 서포트, 브리지)을 따로 둡니다. 값이 노즐 직경에 비해 지나치면 슬라이스 전에 알려줍니다.
- **소구경 노즐 자동 선택:** `Use smaller nozzles in crisp corners`를 켜면 큰 노즐이 채우지 못하는 날카로운 벽 루프를 루프 전체 단위로 작은 노즐에 맡깁니다. 안쪽 벽과 인필은 큰 노즐을 유지합니다. Classic과 Arachne를 모두 지원합니다.
- **인터락킹:** 소구경·대구경 벽 경계를 홀수·짝수 레이어마다 한 줄 이동합니다.

  ```text
  대 대 대 소 소 소 소
  대 대 대 대 소 소 소
  ```

- **대구경 핫엔드 오버라이드:** 시작·종료 레이어와 핫엔드를 지정하면 그 구간은 자동 판정 대신 지정 핫엔드를 씁니다. 여러 구간을 추가할 수 있습니다.

## 절반 높이 외벽·서포트 (H/2)

- `Half-height outer walls`: 바깥 XY 벽 2줄을 레이어 높이의 절반으로 두 번 출력합니다. 전체 벽 수와 안쪽 벽·인필 높이는 그대로입니다.
- `Half-height support`: 서포트를 절반 높이로 출력합니다. 절반 높이 외벽을 켜면 외벽을 받치기 위해 항상 켜집니다.
- 한 레이어 안에서는 아래 반층(서포트·외벽)을 먼저 찍고 위 반층으로 올라갑니다. 위 외벽은 두 외벽 패스 사이 시간이 고르게 되는 위치에 넣어 반층마다 줄무늬가 생기지 않게 합니다.
- 이동 시 Z 들어올림은 레이어 높이의 최소 1.5배입니다.

## 서포트

- **Cura 스타일 일반 서포트:** `Normal (Cura style) auto/manual`. 필요한 영역을 아래로 전달하며 연속 ZigZag 경로를 만듭니다. `Cura solid support raft`로 바닥 첫 층을 100% 채울 수 있습니다.
- **Mixed / Resin 스타일:** 출력 하나에서 일반·트리 서포트를 나눠 쓰거나, SLA식 가는 기둥 지지대를 씁니다.
- **트리 서포트:** 자동 모드의 임계각을 실제 오버행 감지에 씁니다. Tree Slim·Organic 벽 수를 `0~10`으로 지정합니다(`0`은 자동).
- **인터페이스:** 삼각형 패턴(120도 세 방향), 밀도·간격 동기화, 인터페이스 전용 핫엔드, 아랫면 스무딩. 모델에 닿는 면을 1번으로 세어 지정 구간에만 다른 패턴·각도·온도를 쓰는 서브레이어를 지원합니다.
- **저온 인터페이스:** 노즐 하나로 모델과 인터페이스 온도를 나눕니다.

  ```text
  모델 -> 서포트 본체 -> 냉각/온도 전환 -> 인터페이스 -> 재가열 -> 다음 레이어
  ```

  인터페이스 온도는 170°C(펌웨어 냉간 압출 한계) 이상, 필라멘트 최대 온도 이하여야 합니다. 온도 드롭 타워는 슬라이스 전부터 보이고 직접 옮길 수 있습니다.

## GPU 보조 슬라이싱

상단 선택창에서 Vulkan 또는 CUDA를 고릅니다(둘 중 하나만 켜집니다).

- `Vulkan: Auto / On / Max GPU / Off`
- `CUDA: Off / On / Max GPU` (NVIDIA)

형상 결과가 중요한 단계는 CPU 결과로 검증하거나 CPU로 대체합니다. 가속 효과는 GPU, 드라이버, 모델에 따라 다릅니다.

## Snapmaker U1과 캘리브레이션

- **Snapmaker U1:** 네이티브 장치 패널에서 카메라, 현재 레이어, 온도·팬·이동 상태와 주요 제어를 한 화면에서 봅니다. PA 캘리브레이션, 베드 레벨링, 타임랩스는 기본으로 꺼져 있습니다. 프린터·기본 프로세스 값은 Snapmaker 공식 Orca를 따릅니다.
- **LESIC:** 베드 크기에 맞춘 원통형 모델 하나로 온도와 최대 체적 유량을 함께 확인합니다.

## 검증 현황 (2.5.0.1.0)

- 시험: fff_print 167개(1개 skip), libslic3r 223개(1개 skip), half-layer 69개 통과
- OrcaSlicer 가져오기: 실제 사용자 프리셋 62개 가져오기·로드, 55개 값 비교 불일치 0, 다시 가져와도 변화 없음
- 빈 설정 폴더로 GUI 두 번 실행: 첫 실행에 Snapmaker·Voron 설치와 가져오기, 두 번째 실행에 로드 오류 0·파일 변화 0

실제 관리자 설치·제거, 설치본 GUI 화면 조작, 실출력은 이번 릴리스에서 확인하지 않았습니다. 멀티 툴 출력, 장치 전용 시작 G-code, 저온 인터페이스는 장비에 보내기 전에 확인하십시오.

## 소스에서 빌드 (Windows)

```powershell
cmake --build build-vulkan --config Release --parallel 8
powershell -ExecutionPolicy Bypass -File scripts\build_installer.ps1 -BuildDirectory build-vulkan -Parallel 4
```

설치파일 스크립트는 다른 빌드가 실행 중이거나 가용 메모리가 8 GiB, 스테이징 디스크가 20 GiB보다 적으면 시작하지 않습니다.
