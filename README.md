# Magpie Slicer

서로 다른 노즐 구경, 확장된 서포트, GPU 보조 슬라이싱을 하나로 통합한 OrcaSlicer 기반 포크

</div>

**한국어** | [English](README_EN.md)

## 최신 릴리스

- 버전: **2.5.0.0.4**
- 태그: `v2.5.0.0.4`
- 플랫폼: **Windows x64**
- 상태: **Pre-release**
- [GitHub 최신 릴리스 바로가기](https://github.com/Gen7920335/MagpieSlicer/releases/tag/v2.5.0.0.4)

기준 커밋과 SHA-256은 GitHub 릴리스 본문에서 확인할 수 있습니다.

이번 릴리스에서는 최신 PrusaSlicer SLA 서포트를 FFF용 `Resin style (자동)`으로 통합하고 Default/Branching 전략과 세부 설정을 노출했습니다. `Mixed (자동)` 서포트 색칠 채널과 Bambu Lab A2L의 0.2/0.4/0.6/0.8 mm 기기·공정·재질 프로파일도 추가했습니다.

> 개발 중인 포크입니다. 실제 장비에서 출력하기 전에 미리보기와 생성된 G-code를 확인하십시오.

| 저온 인터페이스와 온도 드롭 타워 | 싱글 노즐에서 모델과 인터페이스의 출력 온도를 분리 |

## 멀티 노즐

### 핫엔드별 설정

각 툴헤드는 독립적인 노즐 구경과 선폭을 가집니다. 툴헤드 선택부, 프린터 압출기 설정, `Hotend` 설정은 같은 노즐 구경 원본값을 사용하며 프로젝트와 프리셋에 함께 저장됩니다.

주요 설정은 다음과 같습니다.

- 노즐 직경과 기본 선폭
- 첫 레이어, 외벽, 내벽, 상단 표면, 인필, 서포트 선폭
- 핫엔드 설정과 필라멘트 설정의 개별 저장·불러오기
- 소구경 벽 속도 오버라이드

### 소구경 노즐 자동 선택

`Use smaller nozzles in crisp corners`를 켜면 사용 가능한 핫엔드 중 작은 노즐을 찾습니다. 큰 노즐 경로가 외곽 일부라도 채우지 못하는 연결된 벽 루프는 노즐 전환 자국이 중간에 생기지 않도록 루프 전체를 소구경 노즐로 출력합니다. 안쪽 벽과 인필은 가능한 범위에서 대구경 노즐을 유지합니다.

- 소구경 벽 수는 일반 벽 수와 별도로 지정합니다.
- 공간이 부족하면 소구경 외벽을 우선 보존합니다.
- Classic과 Arachne 벽 생성기를 지원합니다.
- 2번 툴이 더 큰 노즐이면 1번 툴을 소구경으로 역선택할 수 있습니다.

### 멀티 노즐 인터락킹

인터락킹을 켜면 소구경 벽과 대구경 벽의 경계를 홀수·짝수 레이어마다 한 줄 이동합니다.

```text
대 대 대 소 소 소 소
대 대 대 대 소 소 소
대 대 대 소 소 소 소
대 대 대 대 소 소 소
```

벽과 인필의 접촉 경계만 이동하며 인필 패턴 자체는 레이어마다 흔들리지 않습니다.

### 대구경 핫엔드 오버라이드

시작·종료 레이어와 사용할 핫엔드를 지정하면 해당 범위의 소구경 자동 판정을 무시합니다. `Add region`으로 여러 범위를 추가할 수 있으며, 겹치거나 역순으로 입력된 범위는 정규화해서 처리합니다.

### 미리보기

- `Nozzle used`: 노즐 직경별 고정 색상
- `Layer width`: 실제 압출 선폭
- 슬라이싱 시간: G-code 생성과 후처리 완료까지 포함

## 서포트

### Cura 스타일 일반 서포트

기존 Orca/Prusa 스타일 일반 서포트와 트리 서포트를 유지하면서 다음 선택지를 추가했습니다.

- `Normal (Cura style) auto`: 임계각 기반 자동 생성
- `Normal (Cura style)`: 수동·강제 서포트 영역 사용

Cura 스타일은 필요한 영역을 레이어 방향으로 전달하고 연속 ZigZag 경로를 생성합니다. 서포트 토글이 꺼져 있으면 Cura 생성기를 실행하지 않습니다.

`Cura solid support raft`를 켜면 Cura 스타일 서포트의 바닥 첫 층을 100% 채워 베드 접착력을 높입니다. 이 설정은 일반 자동 서포트를 강제로 활성화하지 않습니다.

### 인터페이스

- 삼각형 패턴은 120도 간격의 세 방향만 사용합니다.
- `Interface density / spacing`의 두 값은 서로 변환되어 함께 갱신됩니다.
- 인터페이스 출력 핫엔드를 지정하면 해당 노즐 직경과 서포트 선폭을 사용합니다.
- 지정한 인터페이스 두께를 유지하며 아랫면 스무딩으로 곡면 계단을 완화합니다.

### 인터페이스 서브레이어

모델과 직접 접촉하는 면을 1번으로 보고, 지정한 시작·종료 레이어에만 별도 설정을 적용합니다.

- 기능 켜기/끄기
- 시작·종료 레이어
- 패턴
- 각도
- 온도

범위 끝이 총 인터페이스 레이어 수보다 크면 자동으로 마지막 레이어에 맞추며, 인터페이스가 한 겹뿐이면 비활성화됩니다.

### 저온 인터페이스

싱글 노즐에서 모델과 서포트 인터페이스의 출력 온도를 분리합니다.

```text
모델 -> 서포트 본체 -> 냉각/온도 전환 -> 인터페이스 -> 재가열 -> 다음 레이어
```

온도 드롭 타워는 슬라이싱 전부터 보이고 사용자가 직접 옮길 수 있습니다. 5줄 브림을 사용하며 자동으로 모델을 피해 이동하지 않습니다.

- 온도 차이 30도 이하: 기본 경로 50 mm
- 30도 초과: 1도마다 1 mm 추가
- 최대 경로: 80 mm
- 마지막 10 mm: 10 mm/s
- AUX 팬 냉각과 노즐 와이핑은 지원 하드웨어 프로파일에서만 활성화

### 트리 서포트

- 자동 트리 모드에 설정한 임계각을 실제 오버행 감지에 전달합니다.
- Tree Slim과 Organic의 벽 수를 `0~10`으로 지정할 수 있습니다.
- `0`은 기존 자동값이며, 좁은 가지는 실제로 들어갈 수 있는 벽까지만 생성합니다.

## Vulkan 보조 슬라이싱

상단 선택창에서 다음 모드를 사용할 수 있습니다.

- `Vulkan: Auto`: CPU/GPU 정보를 기준으로 이득이 예상되는 작업만 자동 사용
- `Vulkan: On`: 검증된 GPU 경로를 우선 사용
- `Vulkan: Max GPU`: GPU 적용 범위를 최대로 확장
- `Vulkan: Off`: 기존 CPU 경로만 사용

결과 형상의 안정성이 중요한 단계에는 검증과 CPU 대체 경로가 유지됩니다. GPU 성능, 드라이버, 모델 복잡도에 따라 가속 효과가 달라질 수 있습니다.

## 장치와 캘리브레이션

### Snapmaker 장치 화면

Snapmaker U1용 기본 출력 시작 순서와 네이티브 장치 패널을 확장했습니다. 카메라, 현재 레이어, 온도·팬·이동 상태와 자주 사용하는 장치 제어를 한 화면에서 확인할 수 있습니다. PA 캘리브레이션, 베드 레벨링, 타임랩스 선택창은 기본적으로 꺼진 상태로 표시됩니다.

### LESIC

베드 크기에서 20 mm를 뺀 원통형 캘리브레이션 모델을 중앙에 생성합니다. 바닥 숫자, 외곽 눈금, 내부 브림을 포함하며 소형 베드에서는 글자 크기와 굵기를 조정합니다. 온도와 최대 체적 속도를 한 모델에서 함께 확인할 수 있습니다.

## 빌드

Windows용 기본 빌드는 저장소의 빌드 스크립트를 사용합니다.

```powershell
cmake --build build-vulkan --config Release --parallel 8
powershell -ExecutionPolicy Bypass -File scripts\build_installer.ps1 -BuildDirectory build-vulkan -Parallel 8
```
