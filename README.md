# Magpie Slicer

**한국어** | [English](README_EN.md)

Magpie Slicer는 서로 다른 구경의 노즐을 함께 사용하는 출력과 서포트 생성
기능을 확장한 OrcaSlicer 기반 실험용 포크입니다.

- 프로그램 이름: **Magpie Slicer**
- 현재 버전: **2.5.0 (modified)**
- 설치 패키지 이름: **OrcaSlicer(name pending)**
- 지원 플랫폼: **Windows x64**
- 원본 프로젝트: [OrcaSlicer](https://github.com/OrcaSlicer/OrcaSlicer)

> 이 프로젝트는 개발 중입니다. 실제 장비에서 출력하기 전에 생성된 G-code와
> 장비 동작을 반드시 확인하십시오.

## 주요 기능

### 한눈에 보기

| 기능 | 사용 예시 | 핵심 장점 |
| --- | --- | --- |
| 멀티 노즐 벽 출력 | 0.4 mm로 본체를 빠르게 출력하고 0.2 mm로 글자와 날카로운 외벽 출력 | 속도와 세부 표현을 한 출력물에서 함께 확보 |
| 멀티 노즐 인터락킹 | 소구경 외벽과 대구경 내벽의 경계를 홀수/짝수 레이어마다 이동 | 서로 다른 노즐로 만든 벽의 박리 억제 |
| 대구경 핫엔드 오버라이드 | 강도가 필요한 1~20 레이어만 지정 핫엔드로 출력 | 자동 판정을 유지하면서 특정 구간을 강제로 보강 |
| `Nozzle used` 미리보기 | 슬라이싱 후 각 노즐이 사용된 경로를 색상으로 확인 | 잘못된 툴 배정과 예상 밖의 노즐 사용을 출력 전에 발견 |
| Cura 스타일 일반 서포트 | 곡면 오버행 가장자리를 따라 연속 ZigZag 서포트 생성 | 불필요한 돌출과 격자형 중복 경로 감소 |
| 삼각형 인터페이스와 서브레이어 | 접촉면은 조밀한 삼각형, 내부 레이어는 다른 패턴과 온도 사용 | 접촉 품질, 제거성, 냉각 시간을 분리 조절 |
| 저온 인터페이스와 온도 드롭 타워 | 모델 220 C, 인터페이스 170 C의 싱글 노즐 출력 | 별도 서포트 재료 없이 접촉면 융착 감소 |
| 트리 서포트 벽 수 | 가늘고 높은 트리 가지를 3~5겹 벽으로 보강 | 가지 파손과 출력 중 흔들림 감소 |
| LESIC | 베드 크기에 맞춘 원통으로 온도와 체적 속도 동시 시험 | 별도 모델 편집 없이 장비별 캘리브레이션 |

## 멀티 노즐

### 핫엔드별 노즐과 선폭

기존 재료 중심 설정에 핫엔드 설정을 결합했습니다. 각 핫엔드는 하나의
`nozzle_diameter` 값을 사용하며, 프린터 설정과 좌측 툴헤드 선택 및 내부
`Hotend` 페이지가 같은 값을 공유합니다.

핫엔드마다 다음 선폭을 mm 단위로 설정할 수 있습니다.

| 설정 | 용도 |
| --- | --- |
| 기본 선폭 | 별도 역할값이 없을 때 사용하는 기본값 |
| 첫 레이어 선폭 | 베드 접착을 위한 첫 레이어 경로 |
| 외벽 선폭 | 외관과 치수에 직접 영향을 주는 최외곽 벽 |
| 내벽 선폭 | 외벽 안쪽의 구조 벽 |
| 상단 표면 선폭 | 최상단 표면 |
| 희소 인필 선폭 | 내부 희소 인필 |
| 내부 솔리드 인필 선폭 | 완전히 채워지는 내부 레이어 |
| 서포트 선폭 | 서포트 본체와 관련 경로 |
| 브리지 선폭 | 공중을 가로지르는 브리지 |

노즐 구경을 바꾸면 해당 핫엔드의 자동 선폭 기본값도 갱신됩니다. 사용자가
수동으로 입력한 값은 해당 역할에서 우선 사용합니다. 핫엔드별 값은 서로
독립적이며 최대 16개 툴 선택을 고려합니다.

**사용 예시**

Snapmaker U1의 1번 핫엔드를 0.4 mm, 2번 핫엔드를 0.2 mm로 설정합니다.
1번은 0.42 mm 외벽과 0.45 mm 내벽, 2번은 0.22 mm 외벽과 0.24 mm
내벽을 사용하도록 조절할 수 있습니다.

**장점**

- 노즐 구경만 다르고 선폭은 그대로 남는 설정 불일치를 줄입니다.
- 같은 프로젝트에서 핫엔드별 압출 폭을 명시할 수 있습니다.
- 프린터 프리셋과 프로젝트를 다시 열어도 노즐 및 선폭 구성이 유지됩니다.

### 소구경 노즐 자동 선택

`Use smaller nozzles in crisp corners`를 켜면 슬라이서가 사용 가능한 핫엔드의
노즐 구경을 비교합니다. 자동 모드에서는 기준 핫엔드보다 작은 노즐을 찾고,
수동 모드에서는 사용자가 지정한 디테일 핫엔드를 사용합니다.

어떤 벽을 소구경으로 출력할지는 단순한 각도만으로 결정하지 않습니다.
대구경 노즐의 실제 선폭으로 연결된 벽 루프를 완전히 덮을 수 있는지 계산하고,
조금이라도 채울 수 없는 영역이 있으면 해당 루프 전체를 소구경 대상으로
지정합니다. 루프 내부의 넓은 벽은 대구경으로 유지합니다.

| 설정 | 동작 |
| --- | --- |
| 디테일 핫엔드 | `Auto` 또는 사용할 핫엔드 지정 |
| 소구경 벽 수 | 공간이 허용하는 범위에서 우선 생성할 소구경 외벽 수 |
| 일반 벽 수 | 소구경 벽과 별도로 안쪽에 생성할 기본 벽 수 |
| 노즐 벽 겹침 | 소구경 벽과 대구경 벽 경계의 겹침 비율 |
| 멀티 노즐 인터락킹 레이어 | 홀수/짝수 레이어의 소구경/대구경 경계를 교대 |
| 소구경 벽 속도 | 기존 속도 상속, 절대 mm/s 또는 백분율 |

소구경 벽 수는 일반 벽 수에 포함되어 사라지는 값이 아닙니다. 공간이 부족한
경우에는 소구경 벽을 먼저 보존하고, 물리적으로 들어갈 수 없는 벽만 줄입니다.
Classic과 Arachne에서 같은 설정 경로를 사용합니다.

**사용 예시**

0.4 mm 기본 노즐과 0.15 mm 디테일 노즐을 사용해 음각 글자가 있는
케이스를 출력합니다. 소구경 벽 수를 3으로 지정하면 글자와 날카로운 외곽의
연결된 루프는 최대 3겹까지 0.15 mm 노즐로 만들고, 그 안쪽 구조 벽과
자이로이드 인필은 0.4 mm 노즐로 유지합니다.

**장점**

- 필요한 곳만 소구경으로 출력해 전체 출력 시간 증가를 제한합니다.
- 한 루프 안에서 노즐이 중간에 바뀌어 생기는 추가 심을 방지합니다.
- 소구경 외벽 안쪽을 대구경으로 채워 강도와 출력 속도를 유지합니다.
- 0.6/0.8 mm 핫엔드가 기준일 때 0.4 mm 핫엔드를 역으로 소구경으로
  판별할 수 있습니다.

### 멀티 노즐 인터락킹

인터락킹을 켜면 소구경 벽과 대구경 벽의 경계를 레이어마다 한 벽씩
이동합니다.

예를 들어 대구경 벽 3겹과 소구경 벽 4겹은 다음처럼 배치됩니다.

```text
대 대 대 소 소 소 소
대 대 대 대 소 소 소
대 대 대 소 소 소 소
대 대 대 대 소 소 소
```

외곽 형상과 인필 패턴 자체는 유지하고, 벽과 인필이 만나는 경계만 자연스럽게
이동합니다.

**장점**

- 소구경 벽과 대구경 벽 사이에 수직 박리면이 연속해서 생기는 것을 막습니다.
- 벽과 인필의 접촉 위치가 분산되어 결합력이 좋아집니다.
- 인필 형상을 레이어마다 흔들지 않으므로 내부 구조는 일정하게 유지됩니다.

### 대구경 핫엔드 오버라이드

자동 소구경 판정과 별개로 지정 레이어 범위를 원하는 핫엔드로 강제할 수
있습니다.

- 시작 레이어와 종료 레이어를 좌우 입력칸으로 지정
- 오버라이드할 핫엔드 선택
- `Add region`으로 여러 범위 추가
- 시작/종료값을 반대로 입력해도 범위 정규화
- 범위가 겹쳐도 충돌이나 종료 없이 처리
- 같은 레이어에 여러 범위가 적용되면 목록의 뒤쪽 항목 우선

**사용 예시**

바닥 강도가 중요한 부품에서 1~20 레이어를 0.4 mm 핫엔드로 지정하고,
그 위의 로고와 모서리는 자동 소구경 판정에 맡길 수 있습니다.

**장점**

- 자동 판정 알고리즘을 끄지 않고 특정 높이만 보강할 수 있습니다.
- 바닥, 체결부, 열 삽입 너트 구간처럼 용도가 명확한 높이를 별도로 제어합니다.
- 겹치는 범위를 사용해 더 구체적인 예외 규칙을 뒤에 추가할 수 있습니다.

### `Nozzle used` 미리보기

슬라이싱 결과의 보기 모드에 `Nozzle used`를 추가했습니다.

- 필라멘트 색이 아니라 노즐마다 생성되는 고유 색상 사용
- 여러 핫엔드에서 색상이 겹치지 않도록 팔레트 생성
- 사용 툴 수와 UI 배율이 같으면 범례 크기를 고정
- `Layer width`와 별도로 실제 사용 노즐을 확인

**사용 예시**

슬라이싱 후 `Nozzle used`를 선택해 외벽은 0.2 mm 색상, 내벽과 인필은
0.4 mm 색상인지 확인합니다. 대구경 오버라이드 범위도 레이어 슬라이더로
바로 확인할 수 있습니다.

**장점**

- G-code를 장비에 보내기 전에 잘못된 핫엔드 배정을 찾습니다.
- 같은 필라멘트 색을 사용하는 핫엔드도 노즐 기준으로 구분합니다.
- 범례가 늘었다 줄어드는 화면 흔들림을 줄입니다.

## 서포트

### Cura 스타일 일반 서포트

기존 Orca/Prusa 스타일 일반 서포트와 트리 서포트를 유지하면서 다음 선택지를
추가했습니다.

- `Normal (Cura style) auto`: 임계각으로 자동 감지
- `Normal (Cura style)`: 수동 및 강제 서포트 영역 포함

Cura 스타일 경로는 필요한 서포트 영역을 레이어 방향으로 전달하고 완화한 뒤
연속된 ZigZag 경로를 생성합니다. 결과를 마지막에 잘라 모양만 맞추는 방식이
아니라, 영역 생성과 경로 연결 단계에서 한 줄의 연속 경로가 나오도록
처리합니다.

**사용 예시**

곡면 오버행이 있는 버니나 도넛 모델에 `Normal (Cura style) auto`와 임계각
70도를 적용합니다. 더 넓은 면을 모두 지지해야 할 때는 임계각 90도를
사용합니다.

**장점**

- 위에서 봤을 때 중복 격자나 중앙 연결선이 생기는 현상을 줄입니다.
- 지지가 필요한 면의 경계를 더 가깝게 따라가 불필요한 돌출을 줄입니다.
- ZigZag가 짧게 분할되는 대신 연결된 경로를 사용해 이동과 재시작을 줄입니다.
- 기존 Prusa 스타일과 트리 서포트를 그대로 선택할 수 있어 호환성을 유지합니다.

### 삼각형 서포트 인터페이스

`Support interface pattern`에 `Triangles`를 추가했습니다.

- 기준 각도를 포함한 고정 세 방향
- 각 방향 사이의 각도는 120도
- 다른 임의 방향으로 새는 경로 억제
- 간격 0에서 가능한 최대 밀도로 채움
- Prusa, Cura 스타일 및 트리 서포트 지원

`Interface density / spacing` 이중 입력을 사용하면 밀도나 선 간격 중 익숙한
값을 입력할 수 있고 나머지 값이 함께 계산됩니다. 삼각형 패턴의 밀도는
세 방향의 경로를 기준으로 환산합니다. 인터페이스 출력 핫엔드를 지정하면
해당 핫엔드의 노즐 구경과 서포트 선폭을 사용합니다.

**사용 예시**

평평한 모델 바닥에는 삼각형 패턴, 간격 0, 인터페이스 4겹을 사용해 모든
방향에서 균일하게 지지하도록 설정합니다. 쉽게 제거해야 한다면 간격이나
밀도를 낮춥니다.

**장점**

- 특정 한 방향으로만 약한 인터페이스가 되는 것을 줄입니다.
- 조밀한 접촉면을 만들면서 설정은 기존 간격 방식과 호환됩니다.
- 노즐 구경이 다른 인터페이스 핫엔드를 사용해도 실제 선폭에 맞게 계산됩니다.

### 인터페이스 두께와 아랫면 스무딩

인터페이스는 지정한 레이어 수만큼 실제 두께를 확보하고, 모델 접촉면을
기준으로 각 인터페이스 레이어를 분류합니다. 굴곡진 모델 하단 때문에
인터페이스 아랫면이 과도하게 계단식으로 끊기는 현상을 줄이기 위한 스무딩을
적용합니다.

**장점**

- 인터페이스가 중간에 분리되거나 예상보다 얇아지는 현상을 줄입니다.
- 위아래 형상 차이가 과도하게 커지는 것을 억제합니다.
- 곡면 아래에서도 서포트 본체와 인터페이스의 접촉이 더 연속적입니다.

### 인터페이스 서브레이어

모델과 직접 접촉하는 인터페이스 면을 1번으로 보고, 지정한 중간 레이어
범위에 별도 패턴과 온도를 적용합니다.

| 설정 | 동작 |
| --- | --- |
| Interface sublayer pattern | 기능 켜기/끄기 |
| Start layer | 서브패턴을 시작할 인터페이스 번호, 최소 2 |
| End layer | 서브패턴을 종료할 인터페이스 번호 |
| Pattern type | Rectilinear, Grid, Concentric, Triangles 등 |
| Angle | 서브패턴 출력 각도 |
| Temperature | `0`이면 기존 온도 상속, 그 외에는 별도 온도 사용 |

종료값이 총 인터페이스 레이어 수보다 크면 자동으로 마지막 레이어까지
제한됩니다. 시작과 종료를 같은 값으로 지정해 중간 한 겹만 바꿀 수도
있습니다. 총 인터페이스가 1겹 이하면 기능은 비활성화됩니다.

**사용 예시**

인터페이스가 5겹일 때 2~4번만 Rectilinear 45도와 175 C로 출력하고,
모델 접촉면인 1번과 서포트 본체 쪽 마지막 레이어는 기본 삼각형 패턴으로
유지할 수 있습니다.

**장점**

- 접촉면 품질과 내부 인터페이스의 제거성을 따로 조절합니다.
- 중간 레이어만 냉각하거나 방향을 바꿔 접촉 강도를 세밀하게 조절합니다.
- 전체 인터페이스 패턴을 바꾸지 않고 필요한 구간에만 변화를 줍니다.

### 저온 서포트 인터페이스

싱글 노즐에서도 모델과 서포트 인터페이스의 출력 온도를 분리합니다. 기본
레이어 순서는 다음과 같습니다.

```text
모델 -> 서포트 본체 -> 냉각/온도 전환 -> 인터페이스
     -> 재가열 -> 다음 레이어
```

| 설정 | 동작 |
| --- | --- |
| Low temperature support interface | 전체 기능 켜기/끄기 |
| Support interface temperature | 인터페이스 출력 목표 온도 |
| Interface exit heating time | 모델 출력 복귀 전 추가 재가열 시간 |
| AUX fan cooling | 온도 하강 중 AUX 팬 사용, 유로 어댑터 필요 |
| AUX fan speed | 냉각 중 AUX 팬 출력 |
| Nozzle wiping | 온도 전환 후 프린터 브러시 좌표에서 와이핑 |
| Temperature drop tower | 와이핑이 없거나 냉각 시간이 필요할 때 타워 사용 |

하드웨어 옵션은 프린터 프로파일에 유효한 냉각 위치나 브러시 좌표가 있을 때만
활성화됩니다. 지원하지 않는 장비에서는 해당 동작을 G-code에 넣지 않습니다.

다음 값은 일반 프로세스 GUI가 아니라 장비 프로파일의 하드웨어 데이터로
사용됩니다.

- 노즐 냉각 위치
- 브러시 시작 및 종료 좌표
- 브러시 이동 속도
- 브러시 왕복 횟수

온도 드롭 타워는 다음 규칙을 사용합니다.

- 가능한 베드 좌측 후방에서 모델과 겹치지 않는 위치 탐색
- 온도 차이가 30도 이하면 50 mm
- 30도 초과분은 1도마다 1 mm 추가
- 최대 경로 길이 80 mm
- 마지막 10 mm는 10 mm/s로 감속
- 베드 경계를 벗어나지 않도록 위치 조정

**사용 예시**

PLA 모델을 220 C로 출력하면서 같은 필라멘트의 인터페이스만 170 C로
출력할 수 있습니다. 온도 차이는 50도이므로 타워 경로는 70 mm가 됩니다.
타워를 출력하는 동안 노즐을 식히고, 인터페이스 후 재가열하여 모델 출력으로
복귀합니다.

**장점**

- 별도 서포트 재료 없이 모델과 인터페이스의 과도한 융착을 줄입니다.
- 냉각 대기만 하는 대신 타워를 출력해 압출 상태를 유지합니다.
- AUX 팬, 브러시, 타워를 장비 조건에 맞춰 선택할 수 있습니다.

### 자동 트리 임계각 전달

자동 트리 서포트에서도 사용자가 지정한 임계각을 실제 오버행 감지 단계에
전달합니다. 강제 서포트 페인팅 영역과 자동 임계각 영역을 구분하여, 페인팅
영역이 있다고 해서 자동 감지 결과 전체를 대체하지 않도록 처리합니다.

**사용 예시**

자동 트리에서 임계각을 70도로 사용해 일반 오버행만 지지하거나, 90도로
높여 수평에 가까운 면까지 더 넓게 지지할 수 있습니다. 필요한 작은 부분은
강제 서포트 페인팅으로 추가합니다.

**장점**

- GUI에 입력한 임계각과 실제 트리 생성 범위가 다르게 보이는 문제를 줄입니다.
- 자동 지지와 수동 페인팅을 함께 사용할 수 있습니다.
- 일반, Cura 스타일 및 트리 선택이 서로 다른 생성 경로를 유지합니다.

### 트리 서포트 벽 수

Tree Slim과 Organic 서포트의 벽 수를 0~10 범위에서 지정할 수 있습니다.
`0`은 자동/기본 처리이며, 1~10은 요청한 벽 수를 사용합니다. 공간이 부족한
가는 가지에서는 실제로 들어갈 수 있는 수까지만 생성됩니다.

**사용 예시**

높이가 큰 미니어처의 가는 트리 가지가 흔들리거나 부러진다면 벽 수를
2에서 4로 높여 출력할 수 있습니다. 0.15 mm 노즐을 사용하는 작은 장비에서는
같은 외경 안에 더 많은 얇은 벽을 배치할 수도 있습니다.

**장점**

- 높은 트리 가지의 좌굴과 진동을 줄입니다.
- 무거운 인터페이스를 받치는 가지의 강도를 조절합니다.
- 노즐 구경과 모델 크기에 따라 재료 사용량과 안정성을 선택할 수 있습니다.

## 캘리브레이션

### LESIC

캘리브레이션 메뉴에 베드와 노즐 설정을 읽어 자동 생성되는 원통형 `LESIC`
모델을 추가했습니다.

| 입력 | 기본 용도 |
| --- | --- |
| 시작 온도 | 첫 온도 구간 |
| 종료 온도 | 마지막 온도 구간 |
| 온도 간격 | 구간별 온도 변화량 |
| 온도당 레이어 수 | 각 온도를 유지할 높이 |
| 시작 MVS | 최소 체적 속도 |
| 종료 MVS | 최대 체적 속도 |

- 원통 지름은 베드 크기에서 20 mm를 뺀 범위 안에서 계산
- 베드 중앙 자동 배치
- 바닥 글자는 채움이 아닌 외곽선으로 생성
- 글자와 겹치지 않고 원통 밖으로 나가지 않는 내부 브림
- 200 mm 미만 소형 베드에서는 글자 크기 4 mm와 85% 굵기 적용
- 원주 숫자 라벨과 눈금 포함

**사용 예시**

시작 210 C, 종료 165 C, 1도 간격, 온도당 10레이어와 MVS 8~24를
입력합니다. 선택한 프린터의 베드에 맞는 최대 원통이 중앙에 생성되고,
원주 라벨을 보면서 온도와 체적 속도 변화 구간을 비교할 수 있습니다.

**장점**

- 별도 웹 모델을 내려받고 베드 크기에 맞춰 다시 편집할 필요가 없습니다.
- 온도와 유량 변화 위치가 모델 라벨에 직접 표시됩니다.
- 대형 베드와 Voron 0 계열 소형 베드에서 같은 기능을 사용할 수 있습니다.

## 저장과 호환성

- 핫엔드별 노즐 구경과 선폭은 프린터 프리셋에 저장됩니다.
- 소구경 벽, 인터락킹, 속도 및 오버라이드 범위는 프로세스 설정에 저장됩니다.
- 프로젝트 저장 시 커스텀 설정도 함께 복원됩니다.
- 기존 프로젝트에 커스텀 값이 없으면 기본값을 사용합니다.
- 프린터의 압출기 번호와 툴헤드 번호는 같은 노즐 배열을 참조합니다.
- 기본 OrcaSlicer의 싱글 노즐 및 동일 구경 멀티툴 경로는 커스텀 기능을
  끄면 기존 동작을 유지합니다.

**사용 예시**

4개 핫엔드의 노즐을 각각 0.4, 0.15, 0.6, 0.8 mm로 저장한 뒤 프로젝트를
다시 열면 각 핫엔드의 노즐 및 역할별 선폭과 소구경 설정이 함께 복원됩니다.

**장점**

- 프로젝트를 다른 PC로 옮겼을 때 커스텀 설정 누락을 줄입니다.
- 같은 값을 여러 UI 위치에서 별도로 관리하다가 서로 달라지는 문제를
  방지합니다.
- 커스텀 기능을 사용하지 않는 기존 작업 흐름의 변경을 최소화합니다.

## Windows 빌드

필요한 개발 환경은 원본 OrcaSlicer의 Windows 빌드 환경과 같습니다.

```powershell
powershell -ExecutionPolicy Bypass -File scripts/build_cura_port.ps1
```

Release 실행 파일 경로:

```text
build/src/Release/orca-slicer.exe
```

NSIS 설치 프로그램 빌드:

```powershell
powershell -ExecutionPolicy Bypass -File scripts/build_installer.ps1
```

## 저장소 구성

- `src/`: 프로그램 및 슬라이싱 엔진 소스
- `tests/`: 단위 테스트와 회귀 테스트
- `scripts/`: 빌드, 슬라이싱 및 검증 스크립트
- `resources/`: 프로파일, 번역, 아이콘 및 캘리브레이션 리소스

빌드 결과물, 로컬 샌드박스, 백업 및 검증 출력은 저장소에 포함하지 않습니다.

## 프로젝트 상태

이 저장소는 실험용이며 공식 OrcaSlicer 릴리스가 아닙니다. 모든 프린터
프로파일 및 펌웨어와의 호환성을 보장하지 않습니다.
